# BuildFlow Pro
## Visual Language v1.0

## Purpose

Defines how AI-generated visual assets should look across BuildFlow Pro.

---

# Core Style

Engineering Editorial Minimalism.

Reference feeling:
- Engineering consultancy reports
- Architecture presentation boards
- Professional B2B communication

---

# Illustration Rules

Style:
- Editorial vector
- Minimal
- Technical
- Professional

Avoid:
- cartoon style
- photorealistic AI people
- exaggerated expressions
- consumer app aesthetic

---

# Icon Rules

Style:
- Monoline
- Consistent stroke
- Blueprint inspired
- Technical symbols

Icons must feel like one unified library.

---

# Diagram Rules

Priority:

Clarity > Decoration

Preferred:
- Process flows
- Lifecycle diagrams
- Timelines
- Matrices
- Dashboards

Every diagram should be rebuildable using editable shapes.

---

# AI Visual Generation Principle

AI should create a communication asset, not an artwork.

Every visual must support a business message.
