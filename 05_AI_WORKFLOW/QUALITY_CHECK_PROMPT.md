# BuildFlow Pro Quality Check Prompt

Act as Creative Director and Product Quality Reviewer.

Review the output against:

- MASTER_CONTEXT.md
- PRODUCT_STRATEGY.md
- DESIGN_BIBLE.md
- COMPONENT_RULES.md
- CONTENT_FRAMEWORK.md

Evaluate:

1. Buyer usefulness
2. Construction accuracy
3. Visual consistency
4. Professional credibility
5. Marketplace value
6. Editable usability

Identify:

- weaknesses
- risks
- improvements

Do not approve output only because it looks attractive.
Approve only if it provides commercial value.
