## Quality Standard

Every output must be:

- technically credible
- commercially useful
- visually consistent
- editable where possible
- suitable for international B2B buyers

## Workflow

Follow:

Research → Structure → Message → Layout → Visual → Quality Review

Never skip directly to visual generation.

## Final Self Review

Before delivering output, check:

- Does this solve a buyer problem?
- Does this match BuildFlow Pro identity?
- Would a professional contractor use this?
