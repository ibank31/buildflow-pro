# BuildFlow Pro AI Routing Rules

## Purpose

This document defines how different AI tools should work with the BuildFlow Pro knowledge base.

The GitHub repository is the Single Source of Truth. AI tools are workers, not the database.

Before performing any task, the AI must read the relevant project documents.

---

# Mandatory Reading Rules

## For ALL AI tasks

Always read:

1. `04_AI_CONTEXT/MASTER_CONTEXT.md`
2. `00_PROJECT_CONTROL/PROJECT_STATUS.md`
3. Relevant task documents

Do not create output that conflicts with these files.

# AI Output Rules

Every AI response for this project should identify:

1. Which BuildFlow Pro documents were considered.
2. What task is being performed.
3. Any assumptions made.
4. Whether the output is final or requires review.

---

# Prohibited Behavior

AI must not:

- create generic construction templates
- ignore existing design rules
- change product positioning casually
- generate random assets without buyer purpose
- optimize only for aesthetics

Always optimize for:

Buyer value + commercial usability + professional credibility.
