# BuildFlow Pro MVP Slide Content

## Purpose

This document defines the professional content direction for the first 10-slide prototype.

The objective is not to create decorative presentation slides, but a construction communication system that helps contractors communicate capability, methodology, control, and credibility.

Every slide follows:

Problem → Key Message → Evidence → Visual Communication

---

## Objective

# Production Rule

Do not generate final visuals before validating:

1. Audience
2. Business objective
3. Message clarity
4. Appropriate visual format

The slide must communicate like a professional engineering consultancy document.
