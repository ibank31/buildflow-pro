# Master Slide Design Prompt

Create a premium B2B construction communication presentation for BuildFlow Pro.

Product:
Construction Tender & Project Communication System

Audience:
International contractors, engineering consultants, property developers.

Design direction:
Engineering Editorial Minimalism.

Reference feeling:
AECOM, Arup, McKinsey consulting presentation, engineering annual report.

Requirements:
- clean professional layout
- strong information hierarchy
- technical credibility
- generous whitespace
- precise grid system
- editable presentation structure

Avoid:
- generic construction templates
- orange/black construction clichés
- random stock photos
- cartoon illustrations
- excessive decoration
