# BuildFlow Pro — Content Framework

## Purpose

This document defines the content architecture for BuildFlow Pro: Construction Tender & Project Communication System.

The objective is not to create decorative presentation slides. Each slide must solve a communication problem faced by construction companies, contractors, consultants, and developers.

---

# Content Principle

Every slide follows this sequence:

Problem → Key Message → Evidence → Visual Communication

Avoid generic marketing statements.

Use professional construction communication language.

---

# Buyer Communication Goals

A construction presentation must help the buyer understand:

1. Who the company is
2. Why the company is capable
3. How the project will be executed
4. How risks will be controlled
5. How quality and safety will be managed
6. How progress will be measured

---

# MVP Content Structure

Target: 50–60 slides

## MODULE 1 — Company Capability

Purpose:
Build trust before discussing execution.

Core messages:
- Company profile
- Experience
- Services
- Resources
- Certifications
- Team capability

Buyer question answered:
"Can this company deliver?"

---

## MODULE 2 — Project Understanding

Purpose:
Show that the contractor understands the client's objectives.

Core messages:
- Project overview
- Scope understanding
- Project challenges
- Key requirements
- Stakeholder coordination

Buyer question answered:
"Do they understand our project?"

---

---

# Slide Content Rules

Each slide must have:

- Clear title
- Single communication objective
- Supporting information
- Appropriate visual component

Avoid:

- Long paragraphs
- Empty slogans
- Decorative elements without purpose
- Generic construction imagery

---

# Language Style

Use:

- Professional
- Technical
- Precise
- International B2B tone

Avoid:

- Overpromising
- Casual marketing language
- Empty corporate phrases

---

# Production Rule

Before creating any slide ask:

1. Who is the audience?
2. What decision does this slide support?
3. What information is required?
4. What visual format communicates it best?

This framework becomes the content foundation for all BuildFlow Pro products.
